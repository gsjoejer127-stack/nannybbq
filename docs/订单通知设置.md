# 订单通知设置（约 10 分钟，只需做一次）

做完之后，顾客在网站上点「发送到 WhatsApp」的那一刻，你会同时拿到：

- 一封邮件进 **joejer8278@gmail.com**
- 一行记录进你自己的 **Google 表格**（自动攒成销售流水）

比只靠 WhatsApp 多一层保险：顾客填完资料却没在 WhatsApp 按发送，你照样拿到他的电话，可以主动回访。

---

## 第 1 步　建一个 Google 表格

1. 打开 https://sheets.google.com ，点「空白表格」。
2. 把表格改名为 **BBQ NANNY 订单**（点左上角标题就能改）。

## 第 2 步　贴代码

1. 在这个表格里，点上方菜单 **扩展程序 → Apps Script**。
2. 新分页会打开一个代码编辑器，里面有几行预设的 `function myFunction() {}`。**全选删掉。**
3. 打开本仓库的 `docs/order-notify.gs`，把里面**全部内容**复制，贴进去。
4. 按 Ctrl+S（Mac 是 ⌘S）保存。

## 第 3 步　先测一次

1. 编辑器上方有个函数下拉选单，选 **testNotify**，点「执行」。
2. 第一次会跳出授权画面：
   - 点「审核权限」→ 选你的 Google 账号
   - 出现「Google 尚未验证这个应用」→ 点左下角 **「进阶」→「前往 未命名的项目（不安全）」**
   - 这是你自己写的脚本，不是别人的，所以安全
   - 最后点「允许」
3. 回去看表格，应该多了一行「测试客户」。再看 joejer8278@gmail.com，应该收到一封测试邮件。
4. 确认没问题后，把表格里那行测试数据删掉。

## 第 4 步　部署成网址

1. 编辑器右上角点 **部署 → 新增部署作业**。
2. 左边齿轮图示选 **网页应用**。
3. 设定两项，**这两项错了就收不到通知**：
   - 「执行身分」= **我**
   - 「谁可以存取」= **任何人**（不是「任何拥有 Google 账号的人」）
4. 点「部署」，复制出现的那串 **网页应用网址**，长得像：
   `https://script.google.com/macros/s/AKfy...../exec`

## 第 5 步　把网址给我

把那串网址贴给我，我填进网站代码并上线。

也可以自己改：编辑 `index.html` 第 664 行

```js
var NOTIFY_URL = "";
```

把网址填进引号里，存档后上传到 GitHub 的 main 分支即可。

## 几点要知道

**邮件的含义**　邮件代表「顾客已填好资料并点了发送」，不代表「他真的在 WhatsApp 按了发送」。两边对不上的时候，照邮件里的电话主动联系，这正是加这套东西的意义。

**不会打扰顾客**　上报是后台静默进行的，顾客看不到、也不会慢。万一 Google 那边出问题，网站会直接忽略，顾客照样跳转 WhatsApp 下单，绝不会卡住。

**重复点击**　同一张订单连点几次发送，只会记录一次。

**邮件额度**　免费 Gmail 账号每天可发 100 封，远超实际单量。

**顾客资料存在哪**　全程只经过你自己的 Google 账号，没有第三方公司碰到顾客的姓名电话地址。

**以后改收件信箱**　回到 Apps Script，改最上面那行 `EMAIL_TO`，存档，然后 **部署 → 管理部署作业 → 铅笔图示 → 版本选「新版本」→ 部署**。网址不变。
